# Netflix Data Analysis using R

This project performs **Exploratory Data Analysis (EDA)** on the Netflix Movies and TV Shows dataset using **R**.  
The goal of this project is to analyze trends in Netflix content such as movies vs TV shows, genre popularity, content growth over time, and rating distribution.

---

## Dataset

The dataset contains information about Netflix titles including:

- Title
- Type (Movie / TV Show)
- Country
- Genre
- Release Year
- Rating
- Duration
- Date Added

Dataset source: Netflix Movies and TV Shows Dataset (Kaggle)

---

## Tools and Technologies

- **R Programming**
- **tidyverse**
- **dplyr**
- **ggplot2**
- **lubridate**

---

## Analysis Performed

The following analyses were conducted:

- Movies vs TV Shows distribution
- Growth of Netflix content over the years
- Top countries producing Netflix content
- Most popular genres on Netflix
- Distribution of content ratings
- Movie duration analysis
- Content added trend over time

## Key Insights

- Movies dominate the Netflix catalog compared to TV shows.
- Netflix content production increased significantly after **2016**.
- The **United States produces the highest number of titles**.
- Drama and international movies are among the most common genres.
- Most movies have a duration between **90–120 minutes**.
